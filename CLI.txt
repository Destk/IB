CNTRL + A - В начало строк

Редактирование командной строки

Чтобы быстро исправлять команды, не используя стрелки:

| Действие | Комбинация | Пояснение |
| :--- | :--- | :--- |
| **Навигация по строке** | | |
| Перейти в начало строки | `Ctrl + A` | Полезно, если ошиблись в начале длинной команды . |
| Перейти в конец строки | `Ctrl + E` | Быстрый переход к концу команды . |
| Вперед/назад на 1 символ | `Ctrl + F` / `Ctrl + B` | Аналогично стрелкам вправо/влево . |
| Вперед/назад на 1 слово | `Alt + F` / `Alt + B` | Перемещение между словами (работает не везде) . |
| **Редактирование текста** | | |
| Удалить слово слева | `Ctrl + W` | Удаляет слово до курсора . |
| Удалить всё от курсора до начала | `Ctrl + U` | Аналог "вырезать" до начала строки . |
| Удалить всё от курсора до конца | `Ctrl + K` | Аналог "вырезать" до конца строки . |
| Вставить удаленное | `Ctrl + Y` | Вставка ("вклейка") того, что вырезали `Ctrl+U` или `Ctrl+K` . |
| Очистить экран | `Ctrl + L` | Аналог команды `clear` — делает терминал чистым . |
| Отмена действия/команды | `Ctrl + C` | Прерывает выполнение текущей программы . |

### 2. 🔄 Автодополнение (Tab)

Это **самая важная функция** для ленивого админа. Клавиша **`Tab`** автоматически дописывает команды и имена файлов .

*   **Одно нажатие:** Если есть только один вариант, `bash` допишет его сам.
*   **Два нажатия (`Tab Tab`):** Если вариантов несколько, покажет список возможных вариантов.
*   **Как это использовать:** Начинаете печатать `cd /us`, жмете `Tab` — получите `cd /usr/`. Жмете `Tab` еще раз — увидите список всех папок внутри `/usr`.

### 3. 📜 История команд

Оболочка помнит всё, что вы вводили. Копилка последних 500 команд .

| Команда / Комбинация | Результат |
| :--- | :--- |
| `history` | Показать весь список истории с номерами строк. |
| `Ctrl + R` | **Обратный поиск.** Начинайте печатать часть команды (например, `ssh`), и `bash` сам найдет последнюю похожую команду . |
| `!!` | Повторяет **последнюю** выполненную команду . |
| `!`*число* | Повторяет команду под номером *число* из вывода `history` . |
| `!`*строка* | Повторяет последнюю команду, которая начинается на *строку* . |

1. Вместо стрелок используйте `Ctrl+A/E` для скачков по строке.
2. Вместо копирования мышки используйте `Ctrl+K/U` и `Ctrl+Y`.
3. Вместо того чтобы печатать длинные пути заново, используйте **Tab**.
4. Вместо того чтобы вспоминать сложную команду, нажмите **`Ctrl+R`**.

ПРАВА ДОСТУПА (PERMISSIONS)
1. Введение

Linux — многопользовательская система. Права доступа нужны, чтобы:

    Защитить файлы одного пользователя от другого

    Контролировать, кто может запускать программы

    Ограничить доступ к системным файлам

2. Три категории пользователей
Категория	Символ	Кто это	Пример
Владелец	u (user)	Пользователь, создавший файл	bob
Группа	g (group)	Пользователи в одной группе	users, wheel
Остальные	o (others)	Все остальные на системе	любой, кто не bob и не в users
Все	a (all)	u + g + o вместе	используется в chmod
3. Три типа прав доступа
Право	Символ	Для файла	Для директории
Чтение	r (read)	Просмотр содержимого (cat, less)	Просмотр списка файлов (ls)
Запись	w (write)	Изменение содержимого (nano, vim)	Создание/удаление файлов (touch, rm)
Исполнение	x (execute)	Запуск как программы (./script.sh)	Вход в директорию (cd)
Важно для директорий:

    Без r → не увидите, какие файлы внутри (но если знаете имя — можете обратиться)

    Без w → не сможете создавать или удалять файлы

    Без x → даже не зайдёте внутрь (cd не сработает)

4. Как посмотреть права (команда ls -l)
bash

ls -l

Пример вывода:
text

-rwxr-xr-- 1 bob users 1024 May 17 10:00 script.sh
drwx------ 2 bob users 4096 May 17 10:00 secret
lrwxrwxrwx 1 bob users   10 May 17 10:00 link -> target

Расшифровка первого поля:
text

-rwxr-xr--
│││││││││
││││││││└─── права для остальных (others)
│││││││└──── права для группы (group)
││││││└───── права для владельца (user)
│││││└────── тип файла (см. таблицу ниже)

Типы файлов (первый символ):
Символ	Тип
-	Обычный файл
d	Директория
l	Символическая ссылка
c	Символьное устройство (клавиатура, мышь)
b	Блочное устройство (диск)
p	Именованный канал (pipe)
s	Сокет
Расшифровка примера rwxr-xr--:
Категория	Права	Что означает
Владелец (u)	rwx	читать, писать, исполнять
Группа (g)	r-x	читать, исполнять (но не писать)
Остальные (o)	r--	только читать
5. Изменение прав (команда chmod)
Способ 1: Символьный (буквенный) — понятный для людей

Синтаксис: chmod [категория][операция][право] файл

Категории: u (владелец), g (группа), o (остальные), a (все)

Операции: + (добавить), - (убрать), = (установить точно)

Права: r, w, x
Примеры:
bash

chmod u+x file.txt        # добавить владельцу право на исполнение
chmod g-w file.txt        # убрать у группы право на запись
chmod o=r file.txt        # дать остальным только чтение (убрать всё остальное)
chmod a+x script.sh       # дать право исполнения всем
chmod u=rwx,g=rx,o= file  # владелец: всё, группа: чтение+исполнение, остальные: ничего
chmod -R g+w /shared      # рекурсивно добавить группе запись во всех подпапках

Способ 2: Числовой (восьмеричный) — быстрый и короткий

Вес каждого права:

    r (чтение) = 4

    w (запись) = 2

    x (исполнение) = 1

Складываем цифры для каждой категории:
bash

chmod 755 file.sh   # rwxr-xr-x (7=4+2+1, 5=4+1, 5=4+1)
chmod 644 file.txt  # rw-r--r-- (6=4+2, 4, 4)
chmod 600 secret    # rw------- (6, 0, 0)
chmod 700 script    # rwx------
chmod 777 dangerous # rwxrwxrwx (опасно!)
chmod 400 readonly  # r-------- (только чтение для владельца)

Таблица частых комбинаций:
Число	Права	Когда использовать
644	rw-r--r--	Обычные файлы (стандарт)
755	rwxr-xr-x	Исполняемые файлы, скрипты
600	rw-------	Личные файлы (пароли, ключи)
700	rwx------	Личные папки
664	rw-rw-r--	Общие файлы в команде
775	rwxrwxr-x	Общие папки в команде
400	r--------	Только чтение для владельца
6. Смена владельца и группы
chown — смена владельца
bash

sudo chown bob file.txt        # владельцем становится bob
sudo chown bob:users file.txt  # владелец bob, группа users
sudo chown :users file.txt     # сменить только группу
sudo chown -R bob /home/bob    # рекурсивно (для всей папки)

chgrp — смена группы
bash

sudo chgrp users file.txt      # группа становится users
sudo chgrp -R developers /project

Важно: обычно нужны права sudo, потому что менять владельца могут только root и сам владелец (но владелец не может отдать файл другому пользователю).
7. Маска создания файлов (umask)
Что это?

umask — это "маска", которая определяет, какие права НЕ БУДУТ выданы новому файлу или папке по умолчанию.
Как работает:
text

Максимум для файлов = 666 (rw-rw-rw-)
Максимум для папок  = 777 (rwxrwxrwx)

Новые права = Максимум − umask

Пример с umask 022:
text

Файл: 666 - 022 = 644 (rw-r--r--)
Папка: 777 - 022 = 755 (rwxr-xr-x)

Команды:
bash

umask                    # посмотреть текущую маску (обычно 0022)
umask 002                # изменить маску (для работы в команде)
umask 077                # максимальная секретность

Популярные маски:
umask	Права файлов	Права папок	Для чего
022	644 (rw-r--r--)	755 (rwxr-xr-x)	Стандарт — все читают, пишет только владелец
002	664 (rw-rw-r--)	775 (rwxrwxr-x)	Работа в команде — группа может писать
077	600 (rw-------)	700 (rwx------)	Секретно — только владелец
007	660 (rw-rw----)	770 (rwxrwx---)	Только группа — никто кроме группы
Как сделать маску постоянной:

Добавить в ~/.bashrc (или ~/.config/fish/config.fish):
bash

umask 002

8. Специальные права (setuid, setgid, sticky bit)

Это три дополнительных флага, которые меняют поведение программ и папок.
8.1 setuid (Set User ID)

    Где видно: s вместо x у владельца (rwsr-xr-x)

    Как поставить: chmod u+s файл

    Что делает: программа запускается от имени владельца файла, а не того, кто её запустил

Пример: /usr/bin/passwd имеет setuid root → обычный пользователь может менять пароль (писать в /etc/shadow)

Опасно: неправильный setuid на shell (например, bash) даст любому пользователю права root.
8.2 setgid (Set Group ID)
Для файлов:

    Где видно: s вместо x у группы (rwxr-sr-x)

    Что делает: программа запускается от имени группы файла

Для папок (важно!):

    Что делает: все новые файлы внутри папки получают группу папки, а не группу создателя

    Зачем: чтобы все в команде могли редактировать файлы друг друга

bash

chmod g+s directory
ls -ld directory        # drwxr-sr-x (видите s?)

Пример:
bash

mkdir project
chgrp developers project
chmod g+s project
# Теперь любой файл внутри project принадлежит группе developers

8.3 Sticky bit

    Где видно: t вместо x у остальных (drwxrwxrwt)

    Как поставить: chmod +t папка

    Что делает: только владелец файла может его удалить (даже если у всех есть w)

Где используется: /tmp — у всех есть запись, но удалить чужой файл нельзя
bash

ls -ld /tmp             # drwxrwxrwt (буква t в конце)

Таблица специальных прав
Право	Команда	Где видно	Для файлов	Для папок
setuid	chmod u+s	rwsr-xr-x	Запуск от имени владельца	(не используется)
setgid	chmod g+s	rwxr-sr-x	Запуск от имени группы	Новые файлы → группа папки
sticky	chmod +t	rwxrwxrwt	(не используется)	Только владелец удаляет файлы
Числовое представление специальных прав:

Добавляем четвёртую цифру в начало:

    4 = setuid

    2 = setgid

    1 = sticky

bash

chmod 4755 file    # setuid + rwxr-xr-x
chmod 2755 dir     # setgid + rwxr-xr-x
chmod 1777 /tmp    # sticky + rwxrwxrwx

9. Команды для работы с правами (шпаргалка)
Команда	Что делает	Пример
ls -l	показать права	ls -l file
chmod	изменить права	chmod 755 script
chown	сменить владельца	sudo chown bob file
chgrp	сменить группу	sudo chgrp users file
umask	установить маску по умолчанию	umask 002
Полезные опции:

    -R → рекурсивно (для папок и всего внутри)

    -v → подробный вывод (verbose)

    --reference=файл → скопировать права с другого файла

bash

chmod -R 755 /scripts        # всем файлам в /scripts дать права 755
chmod --reference=template.txt newfile.txt  # скопировать права
