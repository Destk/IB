
## 📁 1. Групповые символы (wildcards)

| Символ | Значение | Пример |
|--------|----------|--------|
| `*` | любая строка | `*.txt` |
| `?` | один символ | `file?.txt` |
| `[abc]` | один из символов | `file[123].txt` |
| `[!abc]` | один **не** из символов | `file[!0-9].txt` |
| `[a-z]` | диапазон | `file[A-Z].txt` |



## 📄 2. cp — копирование


cp источник назначение

| Флаг | Действие |
|------|----------|
| `-i` | спрашивать перед перезаписью |
| `-r` | копировать папки рекурсивно |
| `-a` | архивный режим (сохраняет права) |
| `-u` | копировать, если файл новее |
| `-v` | подробный вывод |


cp file1.txt file2.txt
cp -i file1.txt file2.txt
cp -r dir1/ dir2/
cp *.txt backup/


## 🚚 3. mv — перемещение / переименование


mv источник назначение


| Флаг | Действие |
|------|----------|
| `-i` | спрашивать перед перезаписью |
| `-u` | перемещать, только если новее |
| `-v` | подробный вывод |


mv old.txt new.txt
mv file.txt dir/
mv -i file.txt dir/
mv *.txt dir/


## 🗑️ 4. rm — удаление


rm файл


| Флаг | Действие |
|------|----------|
| `-i` | спрашивать перед удалением |
| `-r` | рекурсивно (папки) |
| `-f` | принудительно (force) |
| `-v` | подробный вывод |


rm file.txt
rm -i file.txt
rm -r dir/
rm -rf dir/

> ⚠️ `rm -rf` — удаляет безвозвратно и без вопросов!

## 🔗 5. ln — ссылки

### Жёсткая ссылка (hard link)
- несколько имён одного файла (один inode)
- ❌ нельзя на папки
- ❌ нельзя между разделами


ln исходник ссылка


### Символическая ссылка (symlink)
- файл-указатель на другой файл/папку
- ✅ можно на папки
- ✅ можно между разделами


ln -s исходник ссылка


### Флаги ln

| Флаг | Действие |
|------|----------|
| `-s` | символическая ссылка |
| `-f` | перезаписать (force) |
| `-i` | спрашивать перед перезаписью |
| `-n` | не переходить по ссылке |
| `-v` | подробный вывод |

ln file.txt hard.txt
ln -s file.txt soft.txt
ln -sf new.txt soft.txt   # перевесить ссылку

ln -s file1.txt link.txt
echo "data1" > file1.txt
cat link.txt          # → data1

# перевесить на другой файл
ln -sf file2.txt link.txt


⚡ Создание алиаса

| Шаг | Команда | Пояснение |
|------|---------|----------|
| 1 | `type имя` | проверить, не занято ли имя |
| 2 | `alias имя='команда'` | создать временный алиас |
| 3 | `echo "alias имя='команда'" >> ~/.bashrc` | добавить навсегда |
| 4 | `source ~/.bashrc` | применить изменения |
| 5 | `unalias имя` | удалить алиас |
| 6 | 'alies'    | Посмотреть все доступные алифсы |



## 🔁 Перенаправления и конвейеры (|)

### Перенаправление ввода/вывода

| Оператор | Действие | Пример |
|----------|----------|--------|
| `>` | перенаправить **stdout** в файл (перезапись) | `echo hello > file.txt` |
| `>>` | перенаправить **stdout** в файл (добавить в конец) | `echo world >> file.txt` |
| `2>` | перенаправить **stderr** (ошибки) | `ls /none 2> error.log` |
| `&>` | перенаправить и stdout, и stderr | `command &> all.log` |
| `2>&1` | перенаправить stderr туда же, куда и stdout | `command > out.log 2>&1` |
| `<` | взять ввод из файла | `sort < list.txt` |

---

### Конвейер (pipe) `|`

Передаёт **stdout** левой команды как **stdin** правой.

команда1 | команда2
