# 🧠 Git — полная шпаргалка (одним блоком)

## 🔁 Базовый цикл
(База для ведения репозитория и минимум работы с гитом)
git status                 # что изменилось?
git add .                  # добавить все изменения
git commit -m "текст"      # сохранить снимок
git push                   # отправить на GitHub
git pull                   # забрать изменения с GitHub
(Раюота с ветками)
git branch                     # список веток (* — текущая)
git branch <имя>               # создать ветку
git checkout <имя>             # переключиться на ветку
git checkout -b <имя>          # создать + переключиться
git switch -c <имя>            # то же самое (Git 2.23+)
git merge <ветка>              # влить ветку в текущую
git branch -d <имя>            # удалить локальную ветку
git push origin --delete <имя> # удалить ветку на GitHub
git push origin <ветка>        # отправить ветку на GitHub
(Работа с удаленным репозиторием)
git remote -v                     # посмотреть привязанные удалённые репозитории
git clone <url>                   # склонировать чужой репозиторий
git clone --depth 1 <url>         # клонировать без истории (быстро)
git push origin main              # отправить локальный main в GitHub
git push origin week1             # отправить ветку week1
git pull origin main              # забрать изменения из main
(Просмотр)
git log                           # полная история
git log --oneline                 # краткая история
git log --oneline --graph         # красивая история с ветками
git diff                          # изменения до add
git diff --staged                 # изменения после add
(Отмена и исправление)
git reset                         # отменить git add (оставить изменения в файлах)
git reset --soft HEAD~1           # отменить последний коммит (оставить изменения)
git reset --hard HEAD~1           # отменить последний коммит (удалить изменения) ⚠️
git add file && git commit --amend # добавить файл в последний коммит
git reset --hard HEAD@{1}         # отменить git pull (срочно)

## 📁 Навигация и файлы

| Команда | Пояснение | Пример |
|---------|-----------|--------|
| `ls` | показать файлы в директории | `ls -la /bin` |
| `cd` | переместиться в директорию | `cd ~` (домой), `cd /` (корень) |
| `pwd` | показать текущую папку | `pwd` |
| `mkdir` | создать папку | `mkdir notes` |
| `touch` | создать пустой файл | `touch script.sh` |
| `rm -rf` | удалить папку и всё внутри | `rm -rf old_folder` |
| `cp -r` | скопировать папку/файл | `cp -r notes/ backup/` |
| `mv` | переместить/переименовать | `mv old.txt new.txt` |
| `cat` | показать содержимое файла | `cat /etc/os-release` |
| `less` | показать файл постранично | `less /var/log/syslog` |
